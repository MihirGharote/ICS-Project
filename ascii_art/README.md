# ASCII Art Generator

![Game Logo](logo.png)

A simple C program that dynamically generates procedural ASCII art for a text-based adventure game. 

## Included Designs

- **STORM GRYPHON**
- **GRANITE NAGA**
- **IRON GOBLIN**
- **COMBAT ENCOUNTER**

## Gallery

```text
STORM GRYPHON

      /v\
   |\0_0//|
    \_^_//
     / | \
    /_ | _\
```

```text
GRANITE NAGA

    _ 0_0
   /_|---'
   [__]
  /_/
  [__]
  \__\
   [__]
```

## How to Build & Run

```bash
gcc generator.c -o generator
./generator
```
